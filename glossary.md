# Словарь терминов
1. Система счисления - способ записи чисел с помощью определенных символов.
2. Основание системы счисления - количество различных символов, используемых в системе.
3. Двоичная система счисления - система с основанием 2, использующая цифры 0 и 1.
4. Восьмеричная система счисления - система с основанием 8, использующая цифры от 0 до 7.
5. Десятичная система счисления - система с основанием 10, использующая цифры от 0 до 9.
6. Шестнадцетеричная система счисления - система с основанием 16, использующая цифры от 0 до 9 и буквы A-F.
7. Разряд - позиция цифры в записи числа.
8. Перевод чисел - процесс преобразования числа из одной системы счисления в другую.
